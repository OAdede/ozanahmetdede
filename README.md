# Kişisel Portfolyo — Ozan Ahmet Dede

Sensörden buluta gerçek zamanlı sistemler kuran bir bilgisayar mühendisinin
kişisel portfolyo sitesi. Saf HTML + CSS + JavaScript ile yazıldı; framework ve build
adımı yok.

## Canlı Site

**https://oadede.github.io/Kisisel-Portfolyo-Web-Sitesi/**

> Not: Link açılmıyorsa GitHub'da **Settings → Pages** bölümünden kaynak olarak
> `main` branch'ini (root) seçmek yeterli.

## Öne Çıkanlar

- 🎛️ "Canlı telemetri" teması: IMU sinyalini andıran animasyonlu dalga formu
- 🌙 Koyu tema, baret sarısı vurgu — Akıllı Baret projesine selam
- 📱 Mobil uyumlu, tek sayfa; eski sayfa adresleri yeni bölümlere yönlenir
- ♿ Klavye odağı, `prefers-reduced-motion` ve erişilebilirlik desteği
- ⚡ Bağımlılık yok: tek HTML, tek CSS, tek JS

## Yerelde Çalıştırma

Herhangi bir sunucu gerekmez — `index.html` dosyasını tarayıcıda açmak yeterli.

```bash
git clone https://github.com/OAdede/Kisisel-Portfolyo-Web-Sitesi.git
cd Kisisel-Portfolyo-Web-Sitesi
start index.html   # Windows
```
